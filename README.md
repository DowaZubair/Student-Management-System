# Student Management System

A beginner-friendly Java console-based Student Management System developed as a semester project.

## Project Overview

This application allows users to manage student records through a simple command-line interface.

Each student record contains:

- Name
- Age
- Grade

## Features

- Add a student
- Display all students
- Search for a student
- Update student information
- Delete a student
- Validate age input
- Handle invalid input
